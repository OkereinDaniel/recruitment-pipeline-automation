# Recruitment Pipeline Automation

## Overview
An AI-powered recruitment workflow automation system built with n8n and OpenAI.

This project automates the hiring pipeline by:
- collecting candidate applications
- analyzing CVs with AI
- ranking applicants
- scheduling interviews
- sending automated emails
- updating recruitment records automatically

---

## Business Problem

Recruiters manually:
- review CVs
- contact candidates
- schedule interviews
- track applicant progress

This process is repetitive, slow, and difficult to scale.

---

## Solution

This workflow automates the recruitment pipeline using AI and workflow automation.

The system:
1. receives candidate applications
2. analyzes CVs using AI
3. generates candidate scores
4. creates summaries
5. updates records automatically
6. sends acceptance/rejection emails
7. schedules interviews
